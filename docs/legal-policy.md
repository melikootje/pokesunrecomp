# Legal and clean-room policy

1. **No game material in this repository, ever.** No Nintendo / Game Freak code, assets, keys, ROM
   data, extracted `exefs/` / `romfs/`, `code.bin`, or recompiled/generated output is committed.
   `.gitignore` blocks the common extensions; reviewers must reject anything else that looks like it.
2. **Bring your own dump.** Users dump a cartridge they own on their own console and run the tools
   locally. The tools accept only *decrypted* dumps and never contain or fetch keys.
3. **Derived metadata only.** Committed analysis output is limited to addresses, sizes, names and
   hashes (e.g. `symbols.json`), never copied bytes or disassembly of game code.
4. **Tests use synthetic fixtures** generated by the test suite itself. Never real game data.
5. **Non-goals:** piracy, distribution of game data, online play against Nintendo services,
   circumvention of encryption (no key material or decryption code is provided).
6. **Contributions** must be original work. Do not paste code from other emulators/decompilations
   unless its license is compatible and it is listed in `THIRD_PARTY_NOTICES.md`.
